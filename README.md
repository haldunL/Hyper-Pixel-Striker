Hyper Pixel Striker is a classic 2D arcade-style fighting game built with retro pixel art aesthetics. It features a responsive 4-button combat system (Light/Heavy Punch and Kick), directional special moves, 4 handcrafted pixel arenas, and a formidable unplayable final boss waiting at the end of the ladder.

Playable Roster: 4 distinct fighters, including projectile-wielding all-rounders, kick-heavy rushdowns, and a heavy-hitting brawler.

Final Boss: An intimidating, non-playable arcade boss featuring punishing damage and high-pressure attacks.

Controls: Traditional 4-button arcade layout with classic motion inputs (quarter-circles and directional thrusts).

Stages: 4 thematic pixel-art battlegrounds (Park, Back Alley, Gym, and Boxing Ring).
